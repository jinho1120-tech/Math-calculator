# Scientific Data Analyzer

논문 및 실험 데이터 분석을 중심으로 한 종합 과학 계산 플랫폼입니다.

## 현재 제공 기능

- CSV / Excel 데이터 불러오기 및 표에서 직접 편집
- 선형, 2~5차 다항, 지수, 로그, 거듭제곱 회귀
- R², RMSE, MAE, SSE 및 지원 모델의 변환 공간 기울기 p-value
- 열별 기술통계: 평균, 표준편차, 분산, 표준오차, 사분위수 등
- 예측값 대비 잔차 그래프 및 행별 잔차 확인
- 분석 데이터 CSV 및 Excel 내보내기

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 통계 해석상 주의

- R², RMSE, MAE는 원래 Y 척도에서 계산합니다.
- 지수·로그·거듭제곱 회귀의 p-value는 변환된 회귀 공간에서 계산한 기울기 검정값이며, 원래 척도에서의 비선형 회귀 검정값과 같지 않습니다.
- 다항 회귀의 개별 계수 유의성 검정, 가중 회귀, 신뢰구간 및 예측구간은 후속 단계에서 추가할 예정입니다.
