# Scientific Data Analyzer

논문 및 실험 데이터 분석을 중심으로 한 종합 과학 계산 플랫폼입니다.

## 현재 제공 기능

- CSV / Excel 데이터 불러오기 및 표에서 직접 편집
- 선형, 2~5차 다항, 지수, 로그, 거듭제곱 회귀
- R², RMSE, MAE, SSE 및 지원 모델의 변환 공간 기울기 p-value
- 열별 기술통계: 평균, 표준편차, 분산, 표준오차, 사분위수 등
- 잔차 그래프 및 행별 잔차 확인
- 측정 표준불확도(1σ) 열을 이용한 오차막대 및 가중 선형회귀
- Pearson 및 Spearman 상관계수와 p-value
- 일반 최소제곱 선형회귀의 점별 95% 평균반응 신뢰구간 및 개별 관측 예측구간
- 분석 데이터 CSV 및 Excel 내보내기

## 가중회귀 및 구간 해석

- 가중 선형회귀는 입력한 표준불확도 σ를 사용하여 w = 1/σ²로 계산합니다. σ는 각 측정값의 절대 표준불확도(1 SD)이며 0보다 커야 합니다.
- 가중회귀의 R², RMSE, MAE는 원래 Y 척도에서 계산합니다. 기울기 p-value는 입력된 절대 불확도를 사용한 가중 최소제곱 공분산으로 계산합니다.
- 신뢰구간과 예측구간은 일반(비가중) 선형회귀에서만 제공하며, 정규성·독립성·등분산성 가정에 따른 점별 구간입니다. 가중회귀 및 다른 회귀모델에는 적용하지 않습니다.
- 지수·로그·거듭제곱 회귀의 p-value는 변환된 회귀 공간의 기울기 검정값이며, 원래 Y 척도에서의 비선형 회귀 검정값과 같지 않습니다.
- 상관계수는 연관성의 크기와 방향을 나타내며 인과관계를 증명하지 않습니다.
